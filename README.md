PC Info Reveal

A free diagnostic tool that scans a Windows PC and shows you everything that matters before you buy or sell it — CPU, RAM, storage, GPU, motherboard, battery, network, installed software, Windows activation, and drive health (SMART data, including SSD wear and power-on hours). Runs as a simple desktop app, no install required.

You'll probably see a security warning before it opens — here's why, and why it's fine:

Windows shows a warning ("Windows protected your PC" / SmartScreen, or an antivirus popup) for almost any script-based tool that isn't from a large, paid publisher with a code-signing certificate. This isn't unique to this tool — it happens because the file wasn't purchased from a certified vendor, not because it's doing something harmful. The tool only reads system information; it doesn't install anything, doesn't modify your system, and doesn't send data anywhere.

To run it:

If SmartScreen blocks it, click "More info" → "Run anyway."
If it's flagged as a downloaded file, right-click the file → Properties → check "Unblock" at the bottom → Apply → then open it.

That's it — after that first click-through, it opens normally.
